Overview

**MPal** is not just a payment clone; it is a sophisticated **FinTech Ecosystem**. Built with a focus on security, intelligence, and scalability, it provides a complete suite for both personal users and business merchants.

Key Pillars
* **Personal:** Secure digital wallet, instant transfers, and real-time spending insights.
* **Business:** Merchant dashboards, automated invoicing, and-programmable payment links.
* **Intelligence:** A cutting-edge AI Risk Engine that predicts and blocks fraudulent transactions in real-time.

## AI Intelligence Engine

The core of MPal is its **AI Brain**, which implements multiple layers of security:
- **Transaction AI:** Analyintzing amounts and frequencies for anomalies.
- **Behavioral AI:** Learning user spending patterns to detect account takeovers.
- **Risk Scoring:** Assigning a real-time score (0-100) to every transaction.
